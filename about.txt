////SQL QUERI UNTUK INSERT CARD PADA TABLE tbl_userlog yang field nya card ,(Jika nilai card pada device Tasoft = null  , maka gunakan triger ini)
DELIMITER $$

CREATE TRIGGER fill_userlog_card 
BEFORE INSERT ON tbl_userlog
FOR EACH ROW
BEGIN
    DECLARE user_card VARCHAR(255);
    
    -- Ambil nilai 'Card' dari tabel usersprofile berdasarkan USER_ADDR
    SELECT Card INTO user_card 
    FROM usersprofile 
    WHERE ID = NEW.USER_ADDR;
    
    -- Jika ditemukan, isi nilai card di tbl_userlog
    IF user_card IS NOT NULL THEN
        SET NEW.card = user_card;
    END IF;
END$$

DELIMITER ;

///END ISSUE/////

Untuk mesin Tasoft Fingerprint untuk card akan berubah karena WG 26 BIT (Nilai Kartu TIDAK SESUAI DENGAN MESIN Tasoft FACE dan soyal)

Maka Sesuaikan Bit rate card yang akan dipakai 
tetapi jika tidak memakai mesin Tasoft Face maka WG 32 card number akan sesuai nilai Card nya
Tasoft Face , Soyal, Nilai memkai WG 32 contoh kartu 555829840
tapi nilai pada Tasoft Finger nilai kartu 6116459

SOLUSINYA IKUTI MESIN KE NILAI WG TERENDAH YAITU MESIN TASFOFT FINGERPRINT

DAN untuk Card Expired Mesin Tasoft Finger print tidak bisa di set jam tetapi hari
